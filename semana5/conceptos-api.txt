La ruta POST /reporte recibe información enviada por el usuario mediante una solicitud POST. El mensaje enviado se guarda en la variable mensaje y el servidor responde con un objeto JSON indicando que el reporte fue recibido.

Esta ruta podría servir en una aplicación comunitaria para recibir reportes de problemas, alertas ciudadanas, daños en infraestructura, situaciones de emergencia o sugerencias de los habitantes de una comunidad.
